# tidewerk

This organisation is a showcase of personal projects: each page describes what a project does and how it is built. The code itself is developed privately.

## Projects

- [Klank](https://github.com/tidewerk/klank): a desktop and Android app for guitar tabs.
- [Maddie](https://github.com/tidewerk/maddie): a self-hosted media manager.
- [Anvil](https://github.com/tidewerk/anvil): a proof of concept that turns a YouTube link into a chord-over-lyrics sheet using audio models.
- [Komi](https://github.com/tidewerk/komi): a Slack-styled chat client for Matrix.
- [Self-hosted platform](https://github.com/tidewerk/platform): a self-hosted platform on Kubernetes (Talos), defined entirely as code with Pulumi, with Git hosting, CI/CD, monitoring, backups, single sign-on and local LLM inference.
- [Design system](https://github.com/tidewerk/design-system): one shared foundation, a theme per product, usage rules and component specifications.
- [Agent kit](https://github.com/tidewerk/agentkit): instructions, skills and guard rails for AI coding agents, written once and generated for each agent.
